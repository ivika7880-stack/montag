# Brandbook — ч/б стиль (профиль настроен через brand-intake)

Этот файл описывает on-screen стиль, который применяют композиции Remotion и разметка
акцентов. Значения ниже — нейтральный пример; замени их своими (или запусти скилл
**`brand-intake`**, он соберёт `brand.config.json` и подскажет, куда прописать).

## Палитра
- Белый текст `#FFFFFF` с чёрной обводкой, фон хука-плашки `#000000`.
- Акцентного цвета нет: выделение ключевых слов — размером и жирностью, не цветом.

Где применяется: цвета в `remotion/src/Shorts916.tsx` (`PAPER` / `SCARLET`, сейчас ещё шаблонные — см. TODO).

## Шрифты
- **Unbounded 700** (`remotion/public/Unbounded-*-700.woff2`, лицензия OFL-1.1, текст — `Unbounded-OFL-LICENSE.txt`) — основной, субтитры слово за словом, строчные. Подобран как максимально близкий к Days со свободной лицензией; жирность усиливает чёрная обводка.
- **Patsy Sans** (`remotion/public/PatsySans.ttf`) — только заголовки-хуки на чёрной скруглённой плашке; наклонный, без заглавных кириллических — выглядит капсом. До 6–8 слов.
- Подключение: `remotion/src/fonts.ts` (`brandFontFamily`, `hookFontFamily`).
- Лицензии: Unbounded — OFL-1.1; Patsy Sans — бесплатно для личного и коммерческого использования (по метаданным файла).

## Тон текста в кадре
- Акцентные слова — КАПСОМ, коротко (1–3 слова на карточку).
- Акцент цветом — дозой: один акцент в кадре, не «ёлка».
- Обращение к зрителю — на выбор («ты» ближе, «вы» строже); держи единообразно.

## Как задать быстро
Запусти `brand-intake` → ответь на вопросы (бренд, шрифт, эффекты, звук, ритм) →
скилл запишет `brand.config.json` и покажет маппинг на файлы выше.
