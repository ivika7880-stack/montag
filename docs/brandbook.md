# Brandbook — шаблон стиля (задай свой)

Этот файл описывает on-screen стиль, который применяют композиции Remotion и разметка
акцентов. Значения ниже — нейтральный пример; замени их своими (или запусти скилл
**`brand-intake`**, он соберёт `brand.config.json` и подскажет, куда прописать).

## Палитра (пример)
- Фон / «бумага»: `#F5F5F5`
- Акцент (дозой — курсор, одно слово в кадре): `#E5484D`
- Тёмный / графит (подложки, тёмные сцены): `#17171A`

Где применяется: цветовые константы в `remotion/src/Main169.tsx` и `remotion/src/Shorts916.tsx`
(`PAPER` / `SCARLET` и inline-стили). Поменяй их под свой бренд.

## Шрифт
Дисплейный капсовый шрифт для акцентов и заголовков. По умолчанию — системный
`brandFontFamily` в `remotion/src/fonts.ts` (websafe стек). Свой шрифт:
положи `.otf/.ttf` в `remotion/public` и подключи через `@font-face` в `fonts.ts`
(пример закомментирован там же), либо возьми Google-шрифт
(см. `.claude/skills/remotion/rules/google-fonts.md`).

## Тон текста в кадре
- Акцентные слова — КАПСОМ, коротко (1–3 слова на карточку).
- Акцент цветом — дозой: один акцент в кадре, не «ёлка».
- Обращение к зрителю — на выбор («ты» ближе, «вы» строже); держи единообразно.

## Как задать быстро
Запусти `brand-intake` → ответь на вопросы (бренд, шрифт, эффекты, звук, ритм) →
скилл запишет `brand.config.json` и покажет маппинг на файлы выше.
