## What this is

A style recipe distilled from one reference reel (Instagram `DeO0rRrtyee`, 720×1280, 30 fps,
128 s, ~25 scene cuts; author on camera, the topic is an advertising scandal that walks
through earlier cases). Contact sheets of the reference: `ref/sheet_1..3.jpg` (0–45 s, 2 fps),
`ref/rest.jpg` (45–128 s, 0.5 fps). **Look at them before building anything.**

Not a template for a topic — a template for *form*: «хук-скандал → "давайте разберёмся" →
цепочка кейсов, каждый подкреплён карточками-доказательствами → вывод → вопрос в комментарии».

Everything below marked **(наблюдение)** is read from the frames/audio of that one reel.
Everything marked **(предположение)** is my guess about how it was made — verify with the user.

## The look (наблюдение)

| Элемент | Как выглядит |
|---|---|
| Чередование | Спикер на камеру ↔ полноэкранные «визуальные» сцены. Визуал идёт под каждую фразу-доказательство, спикер — на выводах, вопросах, эмоциях. |
| Фон визуальных сцен | Вертикальный градиент: насыщенный красный (верх-лево) → почти чёрный. Поверх — тонкое зерно/виньетка (**предположение**). |
| Штамп | Мелкий повёрнутый вертикальный текст в левом нижнем углу визуальных сцен (в стиле видеокамеры, дата `…/…/68`-подобная; точный текст не разобрать). Только на визуальных сценах. |
| Субтитры | Фраза за фразой (3–6 слов), строчными, белый текст на оранжево-красной плашке; на спикере — ниже центра, на визуале — слева сверху. |
| Акцентные слова | Отдельно от плашки: крупный serif-italic (в духе Playfair/Cormorant), кремово-белый или оранжевый, без плашки: «сканда́л в детском мире», «ненормально», «Брук Шилдс», «собрался снимать "Голубую лагуну"», «Calvin Klein», «заработали все:». |
| Первый кадр | Хук: белая плашка на первом слове + serif-italic на втором слове, на спикере. |
| Карточки-стопка | Фото/скриншоты в светлых рамках со скруглением, влетают с небольшим поворотом (±3–8°) и **накапливаются в стопку** — каждая следующая фраза добавляет карточку, предыдущие остаются позади. |
| Вырезки (cutouts) | Ч/б человек, вырезанный по контуру, с неровной «рваной» белой обводкой-стикером; на весь кадр или в углу вместе с serif-подписью. |
| Скриншоты текста | Статьи/комментарии: размытое «прицеливание» → резко, жёлтое выделение маркером на ключевой строке, кусок текста может быть заблюрен. |
| Другое | Мем-картинка (перец с лицом) как реакция, видеофрагмент в рамке-«letterbox» в центре, афиша, запись экрана телефона с наклоном. |
| Темп | Визуальные сцены 1–8 с, внутри — смена карточки каждые ~1–2 с (по фразам). Спикер в одном дубле 2–5 с, jump-cut + punch-zoom на акценте. |
| Лицо | Кроп уже вертикальный (съёмка 9:16), лицо в верхней половине; микрофон-петличка с пушистой ветрозащитой в кадре. |

Доля визуала: **~половина хронометража (предположение по контактным листам, не измерено).**

## What the project can already do vs what is missing

Honest map against `remotion/src/Shorts916.tsx` (read it before promising anything):

| Нужно для этого стиля | Есть в Shorts916 | Статус |
|---|---|---|
| Спикер 9:16, jump-cut, дещелчок-звук, punch-zoom | да (`segments`, `punchZooms`, `audio.py`) | готово |
| Караоке-субтитры капсом + акцентное слово | да, но **стиль другой** (капс, караоке по словам) | нужен второй стиль: «плашка-фраза + serif-italic акцент» |
| Полноэкранная вставка поверх спикера (голос идёт) | да, `layout: "full"` | готово |
| Вставка = один файл на отрезок | да (`inserts[]`) | для стопки нужен **новый тип вставки** |
| Красно-чёрный градиентный фон сцены | — | **написано**: `remotion/src/collage/RedScene.tsx` |
| Стопка карточек с поворотом и накоплением | — | **написано**: `CardStack.tsx` (карточка влетает на якорном кадре) |
| Вырезка с «рваной» белой обводкой | — | **написано**: `Cutout.tsx` (SVG-фильтр; PNG с alpha готовится заранее) |
| Плашка-фраза + serif-italic акцент | — | **написано**: `PlateCaptions.tsx`, шрифт Playfair Display Italic 600 (OFL, кириллица) |
| Штамп в углу | — | **написано**: `VhsStamp.tsx` (текст штампа — проп) |
| Жёлтый маркер / блюр куска скриншота | частично (`coverBox` — только блюр-плита) | **не сделано** |
| Подключение к `Shorts916` + `shorts.py` (вставки типа stack/cutout по якорям) | — | **не сделано** |
| Вырезание фона у фото | нет в репо | внешний шаг (см. Stage 3) |

Статус компонентов: проверены в Studio-композиции `Collage-Demo` на пустышках (typecheck ок, тестовые
кадры отрисованы). Цвет плашки `#E8502F` — приблизительный (на глаз), градиент сэмплирован из кадров.

Поэтому **Stage 4 = сначала собрать недостающие компоненты и показать их в Studio на пустышках,
потом вешать контент.** Не обещай «собрал как референс» до этого.

## Pipeline (per video `<id>`, артефакты в `work/<id>/`)

**Основной случай: видео уже снято.** Сценарий не нужен — материал берётся из записи. Работа
идёт в два слоя: (1) чистка записи, (2) стиль референса поверх чистого монтажа.

**Stage 0 — Вход.** Спроси одним батчем: путь к записи; ориентация (9:16 или 16:9 — от этого
зависит кроп, `shorts.py` умеет оба); есть ли свои скриншоты/фото для визуальных сцен или
собираем список «что найти».

**Stage 1 — Чистка записи (паузы, повторы, неудачные дубли).** Это обычный Stage 1 из
`montage-pipeline`, **не пропускать**:
1. Прокси all-intra H.264 в `remotion/public` (`-crf 15 -g 1 -bf 0 -c:a copy`) + `audio.wav` 16 кГц.
2. `transcribe.py` → `words.json`, `transcript.txt`, `utterances.txt`; `indexed.py` → `indexed.txt`.
3. **Claude** читает `utterances.txt` + `indexed.txt` и пишет `work/<id>/delete.json`: паразиты,
   оговорки, **повторы и неудачные дубли** (из нескольких дублей фразы оставляем лучший —
   последний чистый, если нет причин для другого; спорные пары — в `REVIEW.md` как вопрос).
4. `edl.py` → `edl.json` (паузы сжимаются до ~0.1–0.12 с по порогам в шапке `edl.py`).
5. `review.py` → `REVIEW.md`. **Ворота: показать пользователю, ждать «ок».** Правки только через
   `delete.json` → `edl.py`.
6. `faces.py` → `faces.json` (для 9:16-съёмки tx = 0, лицо не двигаем).

**Stage 2 — Сборка скелета-шортса из чистого монтажа.**
- `shorts.json`: один шорт, `spans` = keep-сегменты из `edl.json` в секундах исходника
  (поля сегментов сверить по реальному `edl.json`, не по памяти); `media` — имя прокси в public.
  Если ролик длиннее минуты-двух — предложи пользователю, резать ли на несколько шортсов.
- Субтитры: Deepgram на русском врёт в именах и числах (на референсе-тесте: «Brookshells»,
  «кексуальное», «Чудесность») — `shorts.py ... draft`, вычитка слов, правки в `fixes`.
- `shorts.py work\<id> remotion\props` → `audio.py remotion\props\<id>.json`.
- Акценты: Claude отмечает слова под serif-italic (имена, цифры, оценки), не больше 1–2 на фразу.
- **Если сценария нет, а фактов в записи много** — составь `work/<id>/facts.md`: имена, цифры,
  цитаты из речи автора с пометкой «источник нужен»; нужен для сбора карточек и для проверки
  на Stage 3. Факты проверяет автор, я их не выдумываю и не «исправляю» молча.

*(Режим «с нуля, ещё не снято» — как раньше: `script-gen` + правило `[ИСТОЧНИК: …]` на каждый
факт; ворота — сценарий и источники утверждены; дальше Stage 1.)*

**Stage 3 — Визуальная карта (`work/<id>/visual_map.md`)** — по `transcript.txt` чистого монтажа. Таблица «фраза → якорь (слово) →
тип сцены → ассет → layout/длительность»:

| # | Якорь (слово) | Тип | Ассет | Эффект |
|---|---|---|---|---|
| 1 | «Patrino» | stack | 3 фото из соцсети | влёт +5°, накопление |
| 2 | «Брук Шилдс» | cutout | ч/б портрет | serif-имя, полный кадр |
| 3 | «ПТСР» | cutout+serif | … | подпись serif |

Типы: `stack`, `cutout`, `screenshot` (+`highlight`/`blurBox`), `clip` (letterbox), `meme`, `poster`.
Правило ритма: смена карточки на каждой смысловой фразе; не больше ~8 с визуала подряд;
после 2–3 визуальных сцен — вернуть спикера. **Ворота: карта утверждена.**

Ассеты — **собирает пользователь** (скриншоты, фото, афиши, записи экрана) в
`work/<id>/assets/`. Я не скачиваю чужие фото из сети без ссылки от пользователя.
Вырезание фона — внешний шаг: инструмент `remove-background` в Canva-коннекторе (если подключён)
или `rembg` (**не установлен в проекте**, ставить — по согласованию). Результат — PNG с alpha в
`remotion/public/inserts/<id>/`.
Генерация картинок (`broll-gen`) для таких сцен **не подходит**: здесь ценность — реальные документы
и фото, а не стилизация. Исключение — абстрактные фоны/мемы.

**Stage 4 — Сборка в Remotion.**
1. Скелет: `shorts.py` → `props/<id>.json`, `audio.py`. Композиция `Short-<id>` (id без `_`).
2. Компоненты (если ещё нет — писать по скиллу `remotion`, версии-пины из CLAUDE.md; тримы в КАДРАХ):
   `RedScene`, `CardStack`, `Cutout`, `PlateCaptions` (плашка + serif-акцент), `VhsStamp`.
   Показать каждый в Studio на пустышке и получить «да» до наполнения.
3. Наполнение: `inserts.json` по якорям из `visual_map.md`.
4. Шрифты: serif-italic с кириллицей (например Playfair Display Italic или Cormorant — **оба
   проверить на кириллицу и лицензию OFL перед подключением**), обычный — из `brand.config.json`.
   Цвета плашки/фона — **сэмплировать из кадров референса**, а не угадывать.

**Stage 5 — Studio.** `cd remotion && npx remotion studio`. Файл не рендерить. Правки →
`shorts.json`/`inserts.json` → `shorts.py` → **`audio.py`** (после каждой правки склеек).

**Stage 6 — Финальный рендер** — только по явной команде пользователя. Затем `publish-pack`.

## Два режима сборки

- **A. Своя запись + чистка + карточки** (основной; запись уже снята — Stage 1–2 выше): спикер снят, визуалы собираются по `visual_map.md`.
- **B. Ремейк самого референса:** есть ссылка → `download.py` (ключи `SCRAPECREATORS_API_KEY`/`APIFY_TOKEN`)
  → `reference.py` → `ref_plan.md`. Подходит для чужого *ролика целиком*; для *стиля* используй режим A.

## Guardrails

- **Чувствительный материал.** Референс — про сексуализацию детей в рекламе, с фото реальных людей,
  включая несовершеннолетних. Для такой темы: только документальные источники, которые автор вправе
  использовать; **никакой генерации** изображений реальных людей и тем более детей; провокационные
  кадры — блюр/кроп/плашка, не вывод на первый план.
- **Права.** Чужие фото, афиши, кадры фильмов, скриншоты — ответственность автора канала
  (цитирование, добросовестное использование зависят от страны; юридический совет я дать не могу).
- **Имена и обвинения.** Формулировки о конкретных людях и брендах — только по источнику, без оценочных
  утверждений от моего имени; спорное — вынести к автору.
- Общие запреты проекта: превью только в Studio, звук голоса не обрабатывать, ничего не рендерить и не пушить без команды.

## Reply pattern

На каждом шаге: на какой стадии мы, что сделано, какой артефакт показываю, какой следующий гейт.
Ворота: сценарий+источники → визуальная карта → компоненты на пустышках → Studio → рендер.
